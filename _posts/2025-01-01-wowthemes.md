## ¿Qué es el tema Mundana y por qué destaca entre otros Jekyll Themes?

**Mundana** es un tema gratuito y de código abierto para Jekyll, mantenido por WowThemes. Está pensado especialmente para blogs y sitios personales con una estética profesional, moderna y sin distracciones. Su enfoque está puesto en el contenido de calidad y la experiencia del lector.

### Características clave del tema Mundana

- **Diseño responsive y minimalista**: Se adapta perfectamente a cualquier dispositivo.
- **Soporte para posts, categorías y autores**: Ideal para blogs multi-tema o colaborativos.
- **Integración con redes sociales y analytics**: Listo para conectar tu presencia digital.
- **Markdown y Disqus listos para usar**: Escribir nunca fue tan sencillo.
- **SEO optimizado**: Metaetiquetas configuradas, URLs amigables y estructura limpia.

### ¿Qué lo diferencia de otros temas similares?

A diferencia de otros temas más genéricos, Mundana incorpora un diseño editorial muy pulido, con una estructura clara que recuerda a medios de comunicación digitales de alta calidad. La paleta de colores, tipografía y organización del contenido están pensados para transmitir confianza, profesionalismo y orden.

## Cómo instalar Mundana en tu sitio Jekyll paso a paso

Uno de los mayores atractivos de trabajar con Jekyll es la facilidad para desplegar sitios estáticos desde GitHub Pages, y Mundana está totalmente optimizado para ello.

### Instrucciones básicas de instalación

1. **Clona el repositorio oficial**:
   ```bash
   git clone https://github.com/wowthemesnet/mundana-jekyll-theme.git
   ```

2. **Instala las dependencias**:
   ```bash
   bundle install
   ```

3. **Levanta el servidor local**:
   ```bash
   bundle exec jekyll serve
   ```

4. **Edita el archivo `_config.yml`** para personalizar los datos del sitio, redes sociales, SEO y autor.
